# Math fonts for large operators

Openly licensed math fonts, used for the document style's "large operators" choice (slanted TeX-style
integrals and display-size sums and products). Bundled with the app, shipped in the installer and installed for
the current user (no administrator rights). Unmodified, each with its licence:

| Font | File | Version | Licence |
|---|---|---|---|
| Latin Modern Math | `latin-modern-math/latinmodern-math.otf` | 1.959 | GUST Font License (LPPL 1.3c): `GUST-FONT-LICENSE.txt`, with the font's README and MANIFEST |
| STIX Two Math | `stix-two-math/STIXTwoMath-Regular.ttf` | 2.12 b168a | SIL Open Font License 1.1: `OFL.txt` |
| XITS Math | `xits-math/xits-math.otf` | 1.108 | SIL Open Font License 1.1: `OFL.txt` |

XITS Math 1.108's name table still carries the older STIX licence wording; the XITS project distributes it under
the OFL 1.1, which is the licence included here.
