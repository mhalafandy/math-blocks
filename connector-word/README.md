# MathBlocks Word Connector

A small COM add-in for Word 2016+ (C#, .NET Framework 4.8) that connects Word to the MathBlocks
desktop app over a named pipe. It has no UI of its own besides a **MathBlocks** ribbon tab.

- `src/Connect.cs`: add-in entry point (ribbon, Word events, request dispatch)
- `src/WordOps.cs`: document operations (insert / read equations, document info)
- `src/PipeClient.cs`: reconnecting named-pipe client
- `src/Rpc.cs`: JSON-RPC helpers, mirror of `packages/connector-protocol`
- `src/SampleEquation.xml`: generated by `pnpm spike:docx` (self-test equation)
- `install/`: per-user install / uninstall scripts (no admin rights)

Build: `dotnet build -c Release src` (any OS with the .NET 8 SDK). Logs: `%LOCALAPPDATA%\MathBlocks\connector.log`.

## Troubleshooting

- **No MathBlocks tab**: File → Options → Add-ins → Manage: COM Add-ins → Go. If "MathBlocks" is
  unticked or listed under *Disabled Items*, enable it and restart Word. Then check the log.
- **Word says the add-in caused a problem**: send `connector.log` and the Word version.
